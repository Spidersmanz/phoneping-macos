# Security

This is an early preview. Accessibility access is powerful and Find My’s interface can change. Review the source and privacy document before granting permission.

Report suspected wrong-device selection, unintended actions, credential access, or network transmission through [GitHub private vulnerability reporting](https://github.com/Spidersmanz/phoneping-macos/security/advisories/new). This channel is enabled. You can also find it under **Security → Report a vulnerability**. Do not put sensitive details in a public issue.

Never include account credentials, location history, or device identifiers in a report. Describe the macOS version, app version, and relevant behavior using synthetic names.

Release binaries should be built from a reviewed tag, Developer ID signed, notarized, and accompanied by checksums. The local preview build is ad-hoc signed and is not a public release artifact.
