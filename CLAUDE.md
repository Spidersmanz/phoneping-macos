# PhonePing

Read `AGENTS.md`, `PRIVACY.md`, and `docs/ARCHITECTURE.md` before reviewing or changing this project.

For reviews, prioritize wrong-device selection, non-sound action paths, stale accessibility elements, timing failures, permission handling, accidental data retention, and whether success messages match the actual evidence. Report actionable findings with file and line references. Do not claim that a phone rang based solely on an accepted accessibility action. Do not approve or merge on the maintainer’s behalf.
